# Kenace's Entity Counter — Feedback

Use this repository to report bugs and suggest improvements for [Kenace's Entity Counter](https://github.com/mickhod/kenaces-entity-counter), a client-side Fabric mod for Minecraft.

## Report a bug

Open an issue using the **Bug report** template. Include:

- Your Minecraft and mod versions
- What happened and what you expected to happen
- Steps to reproduce the problem
- Screenshots or relevant crash and game logs, if available

## Suggest a feature

Open an issue using the **Feature request** template. Explain what you’d like to do, why it would be useful, and how you think it should work. Screenshots or examples are welcome.

## Before opening an issue

- Check existing issues to see whether the problem or suggestion has already been reported.
- Use one issue per bug or feature request.
- Please keep discussion focused on Kenace's Entity Counter.
